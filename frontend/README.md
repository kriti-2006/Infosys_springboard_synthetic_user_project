# Synthetic Persona Platform — Frontend

React + TypeScript + Vite dashboard for the Milestone 3 API. See the repo root `README.md` for full setup
(backend + frontend together) and `docs/architecture.md` for the source layout.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to http://localhost:8000
npm run build   # type-check + production build
```

Requires the backend running on `http://localhost:8000` (see root `README.md`).
